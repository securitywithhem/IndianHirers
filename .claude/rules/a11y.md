# Accessibility — WCAG 2.1 AA

## Contrast pairs allowed

Ratios computed from the token values in `globals.css`. Body text needs 4.5:1;
large text (≥ 24px, or ≥ 18.66px bold) and UI boundaries/icons need 3:1.

| Foreground | On | Ratio | Use |
|---|---|---|---|
| `cream` | `night` / `surface` / `surface-2` | 16.9 / 15.5 / 13.5 | all text |
| `cream` | `maroon-deep` / `maroon` | 13.5 / 9.9 | all text |
| `gold` | `night` / `surface` / `surface-2` / `maroon-deep` | 7.9 / 7.3 / 6.3 / 6.3 | all text |
| `gold` | `maroon` | 4.63 | text ≥ 16px only — little headroom |
| `gold-light` | `night` / `surface` / `maroon-deep` | 12.3 / 11.3 / 9.8 | all text |
| `maroon-deep` or `ink` | `gold` | 6.3 / 7.9 | type on a gold fill |
| `ink` or `maroon-deep` | `whatsapp` | 9.7 / 7.7 | type or icon on WhatsApp green |
| `muted-foreground` | `night` / `surface-2` | 10.5 / 8.4 | secondary text |
| `cream/70` and above | any dark surface | ≥ 5.6 | secondary text |
| `cream/60` | `night` / `surface-2` | 6.5 / 5.8 | captions; **not** on `maroon` (4.50) |

**Forbidden:** `cream` or `white` on `gold` (2.1) · `cream` or `white` on `whatsapp`
(1.8 / 2.0) · `maroon` as text on any dark surface (1.7) · `gold-light` on `gold` (1.6)
· `cream/50` or lower for text · current `destructive` on dark surfaces (3.2–3.9).

A new pair is allowed only after its ratio is computed and added to this table.

## Focus

- Every interactive element shows a visible `focus-visible:` ring: 2px, `ring-gold`
  (or `ring-cream` on a gold fill), with a 2px offset whose colour matches the surface
  underneath (`ring-offset-background`, `ring-offset-maroon-deep`).
- Use `focus-visible:`, never bare `focus:`. Never remove an outline without replacing it.
- Focus order follows visual order. No positive `tabIndex`.

## Structure

- Skip link is the first focusable element and targets `#main-content`.
- Exactly one `<main>` per page — it is in `layout.tsx`; pages must not add another.
- One `<h1>` per page; heading levels never skip. Card titles take their level from
  a prop, not a fixed tag.
- Landmarks: `header`, `nav` (each with a distinct `aria-label`), `main`, `footer`.
- Touch targets ≥ 44×44px with ≥ 8px between them.

## Alt text

- Product and event photos: describe what is in the frame (material, colour, pattern,
  piece), in content files. Never "image of", never the filename.
- Decorative images, textures and repeated logos: `alt=""` plus `aria-hidden`.
- Icons beside visible text are `aria-hidden`; icon-only controls need an `aria-label`.

## Keyboard

**Mobile drawer:** trigger is a `<button>` with `aria-expanded` and `aria-controls`.
On open, focus moves into the drawer and is trapped there; `Esc` closes; on close,
focus returns to the trigger. Background is `inert` and does not scroll. The drawer
is `role="dialog"` `aria-modal="true"` with a label.

**Carousel:** a labelled region (`aria-roledescription="carousel"`). Previous/next are
real buttons, reachable by Tab, with labels. Arrow keys move slides when the carousel
has focus. No auto-advance; if ever added, it needs a visible pause control and stops
on focus or hover. Off-screen slides are not focusable. It must remain a plain,
scrollable list without JavaScript and under reduced motion.

**Forms:** every input has a visible `<label>`; errors are text, linked with
`aria-describedby`, and announced; required fields are marked in the label.
